# Solana

Solana is the active GASLESS V1 network.

This directory contains the account rules, validity windows, semantic wallet policy, and transaction builders used by CLEAN, SWAP, and SEND. Solana-specific concepts such as lamports, associated token accounts, SPL Token, Token-2022 boundaries, versioned transactions, and instruction validation remain here rather than in shared code.

No custom GASLESS onchain program is required for the current V1 architecture.
